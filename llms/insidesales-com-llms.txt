# InsideSales (XANT / InsideSales.com)

> AI-assisted sales engagement platform (Playbooks) that layers cadence, automation,
> prioritization, scoring and call recording on top of an existing CRM — Salesforce, Microsoft
> Dynamics or SAP — rather than replacing it. Branded XANT from 2019 until Aurea Software
> (ESW Capital) completed its acquisition in August 2021 and revived the InsideSales name.
> Generated by API Evangelist on 2026-08-23; the provider publishes no llms.txt of its own
> (https://www.insidesales.com/llms.txt returns 404).

## Read this first

- Machine-readable contract: NONE. InsideSales publishes no OpenAPI, AsyncAPI, GraphQL SDL,
  Postman collection, JSON Schema, .proto or WSDL at any host.
- The only public API is the Playbooks Call Recording API, documented in prose in the help center.
- Every host that API is documented against has been removed from DNS. As of 2026-08-23:
  api.insidesales.com is NXDOMAIN (dangling CNAME into a deleted AWS ELB),
  callrecordings.insidesales.com is SERVFAIL, ci-global-api.pdlmpapis.insidesales.com (the API
  reference) is SERVFAIL, and playbooksmanager.insidesales.com — where an admin mints the API key —
  returns no address record.
- Product release notes stop at 2021-07-09. The status page is titled "Deprecated InsideSales",
  though its four Playbooks regional components still report operational.
- An agent should not attempt to call this API. Verify current access with the vendor first.

## APIs

- [Playbooks Call Recording API](https://helpcenter.insidesales.com/playbooks/call-recording-api/):
  Download a call recording by Call Detail Record (CDR) ID, and — with the second key permission —
  start and stop recording on a live call. Access-key authentication; keys are minted only by a
  Playbooks administrator under Settings > Calls > Call Recording, must carry at least one of two
  permissions, and permissions are immutable after creation. The control (start/stop) half is
  sales-gated: "To begin using this feature please contact your Customer Success Manager."
