Playbooks Solution for Computer-Based Calling How to use Computer-based Calling in Playbooks Playbooks gives reps the flexibility to connect the agent leg either with a phone system (PTSN) or through their computer and internet connection. Computer-based calling creates an Agent Leg and records activity to CRM the same as Phone-based calling but uses the Chrome browser and microphone to complete the call. Download: Playbooks Computer-based Calling Checklist We strongly recommend downloading and completing the Computer-based calling Checklist before attempting to use Computer-based calling.
