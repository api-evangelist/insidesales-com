Enable the Add to Playbooks Button How to Configure Salesforce so the Add to Playbooks Button is Present Playbooks inserts a button into Salesforce that allows users to add records directly from the record page or list views. Some simple configuration is required for the button to appear. Often, Salesforce has these settings enabled already, but there are times where these settings need to be configured.
